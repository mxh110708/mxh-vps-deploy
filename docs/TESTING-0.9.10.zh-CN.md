# v0.9.10 Tunnel 连接流程、后台实测与节点排序修正

2026 年 10 月 9 日使用 [B 方案应用内接口](BACKGROUND-TESTING.zh-CN.md)，在获授权的 YUNYOO 专用测试机追加专属 Cloudflare Tunnel、测试主控与 Agent。由用户配置独立公开路由，应用通过实际安装、审阅、维护、恢复和健康检查控件执行；测试归档与正式归档分离，窗口位于屏幕外，不注入全局输入，不切换系统代理或 TUN。

## 节点排序

扩大左侧手柄的可点击区域，并通过原生路由事件处理按下、移动和释放。拖动时整行跟随，显示序号、落点线与行高亮；长列表支持边缘滚动，完成后保留滚动位置。Esc、取消和失去捕获清理预览并保留顺序；上下按钮与手柄方向键继续可用。

实际 WinUI 后台回归检查手柄中心的原生命中、整行预览随位置移动、落点高亮、释放后方案顺序和旧校验候选失效。回归窗口缩至 1000 × 720 DIP，先滚动使起点与落点进入可视区域，再等待原生命中树就绪；长列表等待实际滚动位置变化后检查放置结果。另覆盖点击不排序、捕获失败、其他指针不能抢占、列表外释放、取消、失效页面、首尾方向键、边缘滚动和滚动后放置；检查深浅两种主题的实际渲染图像。正常界面流程同时检查方案保存、生成、核心校验与两份配置导出。

后台手势接口调用与原生路由事件相同的处理器，支持逐阶段截图；没有注入物理鼠标事件。操作系统实际指针捕获、多显示器和触控体验仍需单独验收，不能把内部手势回归当成这些项目已测。

## Token 归档修复

实测发现 Tunnel 重连完成后，远端 Token 已生效，本地当前用户的 DPAPI 加密归档仍保留旧值。修正为远端更新及连接验收成功后再写入加密归档，并沿用事务提交与恢复；提交未确认时恢复旧值，其他凭据字段保持原内容。

回归先验证旧实现会出现归档不一致，再验证正常提交保存新值、丢失提交确认并确认回滚后恢复旧值。修复后的原生维护再次连接测试 Tunnel，核对远端 Token 文件与解密后的本地值相同，并通过公网 WebSocket 确认 Agent 持续更新。

## 先连接再继续

安装表单明确说明先建立 Tunnel 并取得连接 Token，安装连接后才在 Cloudflare 配置公开路由。实例页提供准确的本机服务 URL、公开主机名、验证入口与上次结果。组合安装调整为先主控、再 Tunnel、最后 Agent；三项一起追加时，在 Agent Token 输入前提示登录主控和创建节点，取消仍恢复整轮新增组件。

实测发现默认 Python 请求标识被 Cloudflare 拒绝，而同一接口使用应用标识正常返回。探测改为明确的应用请求标识和 JSON 接受类型，保留严格证书检查、不跟随重定向、不发送账号或 Token；HTTP 拒绝显示状态码。最终探测在 VPS 上通过，控制端另完成 16 项真实 HTTPS、登录和 WebSocket 检查。

共享核心通过 439 项边界与工作流断言，包括准备 Agent 时取消和范围恢复、公开访问检查不变更远端、失败保留正确网址与其他凭据。实际探测脚本的 12 项隔离测试覆盖路由缺失、DNS、TLS、HTTP、超时、错误内容、错误版本、重定向及请求标识。原生 WinUI 检查深浅两种路由指引与安装表单，并覆盖归档迁移后及网址从有效改为无效再改回有效的按钮和主机名刷新；回归等待实际控件状态。同版本接口可达不代表主控唯一身份验证。

## 收尾与边界

第一轮收尾先通过正常应用卸载本轮 Agent；两轮均核对初始不存在的主控与 Tunnel 路径、程序摘要、服务定义和原部署摘要，清理本轮程序、服务、Token 与活动测试数据。保留共享服务账号、系统日志及受保护的历史恢复材料；这不是全新系统重装。

最后复核原 Reality 与防火墙摘要、主与救援 SSH、正常应用健康检查以及正式归档文件摘要。Cloudflare 上由用户创建的测试路由和专属凭据保留；本轮连接器停止后，该公开地址不再提供本轮测试主控。

本轮 Token 更新验证的是同一凭据的合法不同编码及错误值恢复，没有在 Cloudflare 控制台轮换、吊销或修改账号密钥。真实签发端轮换、IPv6 专用 Tunnel、旧主控数据库迁移、所有断网组合和物理拖动仍未覆盖。其他协议结果见 [v0.9.9](TESTING-0.9.9.zh-CN.md)、[v0.9.8](TESTING-0.9.8.zh-CN.md)和 [v0.9.7](TESTING-0.9.7.zh-CN.md)。

更新与安装机制没有变化，本轮不重复完整本地生命周期；正式发布核对最终提交 CI、正式原生启动以及四个发行资产的大小与 SHA-256，既有 Windows CI 保留单次安装器检查。
