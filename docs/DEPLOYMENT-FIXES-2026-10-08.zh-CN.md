# v0.9.2 部署体验修正

本轮修正首次部署测试暴露的连接、任务状态和交互缺漏。验证使用模拟状态、临时归档和本机 SSH/SFTP 服务；不代表已经部署或验收生产 VPS。桌面发行继续不同步旧命令行目录。

## 首次身份与连接

原实现把人工弹窗放在 SSH 主机密钥回调中等待，这段等待消耗连接握手的超时。现在未知身份探测会立即拒绝并结束连接，取得指纹后才等待使用者；确认完成再建立正式 SSH 和 SFTP。只允许这一次连接前的身份探测，不重试或重放远端写入。

窗口显示实例、服务器与端口，说明首次信任的含义。指纹可以选择或复制；展开说明后可在服务商网页控制台独立读取对应主机公钥的 SHA256 指纹，再粘贴结果自动比较。参考指纹不一致、格式不完整或出现多个指纹时禁止连接。没有独立参考时按钮明确表示首次信任，不冒充独立核验。已信任的同一身份自动通过；重装等导致身份变化时保留旧记录并拒绝连接，需维护者独立核对后按明确任务处理。

## 审阅与表单

- 默认节点名称由服务商和实例组成，空白转换为连字符；未自定义时跟随输入，自定义后不被覆盖，清空后重新生成。已保存实例不改名。
- Komari 地址仅在新部署勾选 Agent 时显示并进入计划。Agent Token 仍在执行时输入。
- 审阅窗口滚动展示对象、系统要求、当前/规划 SSH、认证方式、所选用途、核心版本、协议端口、目标/出口、证书与监控、防火墙、执行顺序、失败处理、归档与验收。
- 计划中的系统、目标和监听参数明确尚未实际检查。继续草稿使用已保存的计划和当前归档端口；表单修改不覆盖它。

## 失败、取消与继续

记录显示具体阶段、安全原因、错误代码和建议下一步。SSH 超时、网络拒绝、登录认证、身份改变、SFTP 权限/路径、远端退出码及本地读写分别分类；未知异常只记录类型，不输出可能含凭据的原始消息或远端错误全文。

当前步骤结束后写入失败/取消/待恢复状态与时间，不遗留 Running。部署失败记录独立保留，之后只读核对不会抹掉部署原因。实例页区分未完成草稿与完成归档；草稿提供继续部署或继续接入，完成实例进入具体维护。

第一次读取失败尚无事务时，“未完成任务”会说明无需回滚并指引继续草稿，不无意义地再访问远端事务接口。遇到基线或维护事务未确认时阻止直接续作、调优或删除，先核对真实身份与状态再按范围恢复。已完成部署/接入不能通过继续按钮重放部署。接入必须完成本地配置归档和导出后才标记完成。

## 删除本地实例

“删除实例”与远端“实例退役”是两项明确操作。删除前显示实例、目录、文件数量和总大小，删除该实例目录内的计划、状态、加密凭据、管理密钥副本、配置、备份及原资料副本。

使用实例协调锁和原运行锁，拒绝运行中、未确认事务、路径链接、身份不一致和审阅后文件变化。核对后在应用私人范围内分离并删除目录，不生成长期备份。共享协调锁位于全局目录，避免 Windows 持有目录内文件句柄时无法移动实例。

保留服务商源私钥、外部客户端权威、其他实例、应用设置、主机信任和任务历史。删除只清理本地材料，不连接 VPS、不关闭远端服务、不撤销远端密钥；清理后重新部署仍需先确保服务器适合新机流程。远端卸载仍由“实例退役”明确选择范围。

## 验证边界

行为回归覆盖自动命名/自定义、监控隐藏、审阅不泄密、首次指纹比较、失败/取消状态、无事务核对、草稿续作、完成状态，以及删除的锁、摘要、事务、身份、链接和外部文件边界。

实际 SSH.NET 本机测试使用生成的临时密钥和虚拟账号：连接超时为 3 秒，人工确认等待 6 秒后仍完成 SSH/SFTP；确认前无登录认证，可信身份无需再次确认，错误密码给出认证原因，取消不保存信任，变化身份拒绝且不发送凭据。WinUI 验证只使用显式隔离工作区，检查表单、审阅/身份/删除弹窗及草稿操作，并取消实际执行。

更新功能、安装器行为与公开资产结构没有改动，继续使用正式安装版的应用内原位更新。本轮不重复下载已发布更新或完整安装生命周期验证；正式包仍进行原生 EXE 七页面加载、秘密扫描和附件摘要核对，当前提交的远端 CI 通过后发布。
