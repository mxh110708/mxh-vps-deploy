## 边界与发布门槛

AnyTLS/ECH 缺少本轮专用域名与 DNS 授权材料，Tunnel 缺少专属 Token，其真实证书签发、联网连接与公开域名路由明确未测。其表单、参数、依赖顺序与范围恢复由隔离回归验证；按使用者选择继续完成其他测试并发布。

本轮没有重新执行全新重装部署、IPv6 专用 SS 第二用户、旧版主控数据库跨版本迁移或所有网络故障组合。上一版单项追加和 Agent 上报、维护的实机范围见 [v0.9.7 记录](TESTING-0.9.7.zh-CN.md)。

正式发行要求干净 main、稳定版本元数据、最终提交的两个 GitHub CI 工作流成功，以及四个发行文件的大小和 SHA-256 摘要一致。原有安装器生命周期验证仅在 Windows Python 3.13/runner CI 中执行一次；本轮未修改更新流程，没有重复新版发现、下载、校验和安装的完整本地链路。
