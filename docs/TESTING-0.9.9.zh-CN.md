# v0.9.9 AnyTLS/ECH 后台实测

2026 年 10 月 9 日使用 [B 方案应用内接口](BACKGROUND-TESTING.zh-CN.md)，在获授权的 YUNYOO 专用测试机补做 AnyTLS/ECH 联网项目。应用使用独立私人归档和屏幕外原生窗口，调用实际追加安装、审阅、维护与健康检查控件；不注入系统鼠标或键盘，不切换系统代理或 TUN。

## 修正与回归

AnyTLS 安装器原来的 `Conflicts=xray.service` 会让 systemd 在启动 AnyTLS 时停止已有 Reality，即使两个入口使用独立端口。发现后先在证书安全边界取消安装，确认本轮事务恢复，再移除冲突定义并重新实测。显式协议切换和端口冲突检查保留原行为。

共存回归读取安装器实际生成的服务定义，并模拟 systemd 的冲突停止行为。仅在测试内存中恢复旧定义时，该用例能发现故障；修正后独立端口共存通过，共用端口仍在服务变更前被拒绝。本地 `ValidateProject`、修改脚本的 Bash 语法和 ShellCheck 警告检查通过；Windows 链接权限用例由 Linux CI 执行。

## YUNYOO 实测结果

| 项目 | 结果与证据范围 |
|---|---|
| DNS 授权与解析 | 从专用服务器核对 Token 有效性、目标区域读取权限及测试域名的 DNS-only 记录；签发过程实际验证 DNS 编辑权限 |
| 错误 Token | 通过真实表单提交合成错误 Token，安装失败并确认 `RolledBack`；Reality 配置、服务和防火墙保留，本轮凭据文件移除 |
| 证书阶段取消 | 通过应用正常取消按钮请求取消，任务在安全边界恢复；Reality 和防火墙摘要一致，AnyTLS 服务尚未安装 |
| 正式证书 | 为本轮两个测试名称签发可信证书，核对 SAN、有效期及 TLS 配置；不使用自签名证书替代 |
| 自动续期 | 安装步骤中的续期 dry-run 成功；专用续期 timer 启用并运行，发行版重复 timer 停用，Token 文件权限为 0600 |
| 共存安装 | 使用正常追加安装流程，只选择 AnyTLS；安装后 AnyTLS 与原 Reality 同时运行，原 Reality 配置摘要一致，事务已提交 |
| 双核心真实连接 | Reality 主、备用入口及 AnyTLS/ECH 分别使用固定 sing-box / Mihomo，6 项验收全部通过，包含 HTTPS、实际出口匹配和 SOCKS UDP DNS |
| 安装后健康检查 | 正常应用健康检查通过，协议状态及私人归档回填完成 |
| 正常停用与卸载 | 两项均由正常应用协议管理执行、完成事务提交；剩余 Reality 双核心验收及最终健康检查通过 |
| 本轮文件清理 | AnyTLS 服务、程序、配置与监听移除；按初始不存在的目录及逐文件摘要清理本轮证书、DNS 凭据与续期服务，测试 DNS 挑战记录无残留，防火墙回到初始摘要 |
| 管理连接与归档保留 | 原 Reality 配置摘要一致并持续运行；主、救援 SSH 均通过已信任主机身份和管理密钥认证；正式归档 17 个文件的数量与摘要保持一致 |
| 焦点与输入 | 本轮任务窗口激活次数与前台采样均为 0，没有全局输入或虚拟机 |

原始截图、配置、证书摘要、各入口结果、事务与清理证明留在本地私人测试目录；公开记录不包含测试地址、连接端口、域名、联系邮箱或凭据。正式应用与私人归档没有被测试副本覆盖。

Certbot 软件包、系统日志和受保护的历史恢复材料保留，未卸载共享系统工具。当前活动的证书目录、Token 文件、测试续期服务和代理组件已清理；这不是全新系统重装。

## 未测项目

Cloudflare Tunnel 仍缺少专属测试 Token 和路由，因此本轮未验证其连接、公开域名访问或 Token 轮换；没有复用正式监控 Tunnel。LAX 的历史 DNS 记录和其他 VPS 未纳入操作范围。

本轮没有重做全新系统部署、IPv6 专用 SS 第二用户、旧版主控数据库迁移或所有断网组合。物理拖动、系统托盘鼠标菜单、文件选择器和 UAC 等体验也未通过电脑操控验证。之前的多组件追加、SS、Komari 主控与 Agent 范围分别见 [v0.9.8](TESTING-0.9.8.zh-CN.md) 和 [v0.9.7](TESTING-0.9.7.zh-CN.md)。

更新及安装机制未改变，本轮不重复完整本地更新生命周期；正式发行仍核对最终提交的 CI 结果、四个发行资产的大小与 SHA-256，并由既有 Windows CI 单次运行安装器检查。
