# 维护与记录调整 · v0.9.3

## 选择实例

选择框收起时，滚轮不会切换选中的实例，页面仍可正常滚动。需要更换实例时展开列表并明确选择；展开后的列表滚动保留。当前实例在维护弹窗和最终审阅中显示。

## 代理核心升级

“组件升级”改为“升级核心”。对象是当前 VPS 上的代理程序，不是 Windows 桌面应用。桌面应用更新仍在设置页进行。

| 选择对象 | 更新程序 | 对应服务 |
|---|---|---|
| Xray · Reality 入口 | Xray | xray |
| sing-box · AnyTLS / ECH 入口 | AnyTLS 专用 sing-box | sing-box-anytls |
| sing-box · Shadowsocks 落地 | Shadowsocks 专用 sing-box | sing-box |

只列出已有受管安装记录的服务；明确卸载的协议不会因默认用途名称而重新出现。停用协议须先启用才能升级并验收。窗口显示归档版本、目标版本、服务名称和步骤。目标来自应用支持的固定版本，不把本地归档当作实时远端状态；归档与目标一致时明确说明继续会重新安装并校验。

升级前核对远端协议状态、备份，更新所选程序并重启相应服务，再独立验收。现有协议恢复点仍覆盖本机受管代理协议；失败按该恢复范围处理，不包含监控、SSH 或网络调优。不同 sing-box 服务分别选择，不因程序名称相同而合并维护。

## 监控与访问

三个组件分别提供入口，不再让用户选择监控组件后同时选择代理协议。

| 组件 | 用途 | 操作 |
|---|---|---|
| Komari Agent | 采集当前 VPS 指标，向主控上报 | 升级、卸载 |
| Komari 主控 | 当前 VPS 上的监控数据和网页面板 | 升级、一致性备份、恢复主控专用备份 |
| Cloudflare Tunnel | 将本机主控网页连接到 Cloudflare 入口 | 轮换本机连接 Token |

未纳管的组件禁用操作，不能借升级入口安装 Agent 或主控。执行前再次只读核对远端是否安装；实际状态不符时在写入备份和组件变更之前停止。

Agent 升级保留配置和原启停状态，成功后记录固定版本；卸载停止上报，保留主控中的历史数据。主控一致性备份、升级或恢复会短暂停止主控，再恢复原启停状态；只使用明确标记不包含 Tunnel 的专用备份，没有恢复点时禁用执行。Tunnel 入口只更换本机连接 Token 并重启 Tunnel，不修改 Cloudflare DNS、主控数据或 Agent。

## 任务记录

每条记录有删除入口，顶部可清空全部列表。单条审阅显示任务、实例和时间；全部清空显示记录数量。删除只更新 `private/task-history.dotnet.json`，保留其他归档、备份、配置导出事务和未完成事务的恢复材料。删除列表条目不能消除真实的待恢复状态。

列表读写共用文件锁。正在执行的已识别实例任务不能删除；审阅后有新记录或内容变化时，要求重新选择，避免清空新生成的结果。上次异常退出留下的运行中条目在确认实例没有任务占用后可以清理。格式损坏时保留原文件并说明原因。

卡片只显示实际存在的字段，用中文任务名和本地时间呈现；失败原因、错误代码、下一步保持可见。新维护任务同时保存具体操作对象，旧记录保持可读取。

## 验证与边界

共享核心回归覆盖单条删除、清空、过期审阅、运行锁、损坏记录保护、恢复材料保留、组件范围和版本检查。模拟 Agent 升级只备份 Agent，不调用代理安装或状态写入；远端组件缺失在写入前停止。

隔离原生 WinUI 窗口检查滚轮事件、显式选择、记录列表与删除弹窗、主控空恢复点、未安装 Agent 的禁用状态、代理和监控弹窗，以及深浅模式。使用示例地址和合成归档，没有生产 VPS 连接。这些验证不代表真实 VPS 维护已经验收，后续由用户实测。

本轮不改更新或安装流程，不重复隔离环境的公开更新下载验证，不同步旧命令行使用目录。
