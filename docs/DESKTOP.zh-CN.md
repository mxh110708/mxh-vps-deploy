# Windows 桌面版

桌面版从正式 v0.6.0 起提供。桌面端使用 Windows WPF 与现有 PowerShell 后端，不需要另外安装浏览器运行时。

## 启动

双击应用目录中的 `Start-VPSDeploy.cmd`。需要 Windows 10/11 amd64 和 PowerShell 7.4+；客户端配置构建仍需要 Python 3.9+ 与项目固定的 YAML 依赖。初始 SSH 图形认证的轻量辅助程序使用 Windows 自带 .NET Framework 编译器生成在应用缓存中。

需要终端或脚本自动化时使用 `Start-VPSDeploy.Cli.cmd`、`Start-VPSDeploy.ps1`，原参数和交互语义保留。同一应用目录只允许一个桌面窗口运行。

## 桌面使用逻辑

| 页面 | 使用方式 |
|---|---|
| 概述 | 查看本地归档数量，进入部署、维护、客户端配置或本地自检 |
| 实例 | 选择实例，查看本地用途及部署记录，再进入运维、协议、继续部署或网络参数 |
| 部署 | 一次填写服务商、实例、地址和 SSH 等基础信息；配置选项、审阅与执行分开 |
| 客户端 | 创建、打开方案或从现有配置创建；编辑、候选生成、校验与发布分开 |
| 记录 | 查看近期任务结果和本次窗口的执行详情 |
| 设置 | 调整界面大小、检查应用更新和查看数据位置 |

填写基础表单或点击页面导航不会连接服务器。表单在页面内显示校验错误；填写完成后由原后端继续校验配置选项，审阅完整摘要并确认执行。高级参数按实际角色显示，重要提示和确认短语保留。

操作菜单使用按钮，节点多选使用可直接点击的列表；凭据使用隐藏输入框，路径字段提供浏览按钮。初始 root 密码或 SSH 认证提示通过图形窗口处理，不需要在隐藏终端输入。

后台操作期间可以切换页面，通过“返回当前任务”继续。取消会等待可返回的位置，部署在模块之间停止；关闭窗口同样等待安全边界。已完成的操作和归档保留。取消或关闭正在编辑的客户端方案会保存当前已完成编辑的加密草稿；尚未确认的单项编辑不自动提交。取消、失败、有提示结束分别显示，不把用户跳过记为验收通过。

## 应用数据

```text
<应用目录>/
├─ Start-VPSDeploy.cmd
├─ config/
│  ├─ app-defaults.local.json        原有本机覆盖文件，保留
│  └─ client-layout.local.json       原有客户端偏好，保留
└─ private/
   ├─ instances/<服务商>/<实例>/MXH-VPS-Deploy/
   │  ├─ deployment-plan.json
   │  ├─ deployment-state.json
   │  ├─ deployment.log
   │  ├─ ssh/
   │  └─ ...                        原有实例档案和恢复材料
   ├─ client-schemes/               当前 Windows 用户加密的方案
   ├─ client-candidates/            待校验/发布的私人候选
   ├─ client-publish/               双文件发布事务与必要恢复材料
   ├─ gui-settings.json             界面大小、自动检查偏好
   └─ task-history.json             最近 120 项任务的时间、类型和结果
```

桌面端不读取命令行的外部归档根目录偏好，也不扫描、搬迁或删除旧实例目录。已有归档切换到桌面版时由维护者离线转换并核对活动路径和校验值；应用不设置一次性导入入口。

“记录”中的任务结果可在重开后查看，不记录输入值或凭据。本次执行详情只保留在当前窗口；实例的长期运维日志仍由原后端写入私人归档。客户端来源和最终权威文件可保持其现有外部位置，读取与发布沿用原指纹检查和明确确认。

## 应用更新

设置页提供“自动检查更新”开关、“检查更新”和“更新并重启”。自动检查默认关闭，打开后在启动时检查正式 GitHub Release；发现更新后仍需点击更新按钮，不自动安装。可临时填写 HTTP/HTTPS 代理供应用更新使用，不切换系统代理。

下载只接受本项目正式 Release 的指定 Windows 包及 SHA-256 文件，并核对 GitHub 附件摘要、包摘要和逐文件清单。更新等待当前窗口退出后替换受管应用文件并重新启动，私人数据、`.local.json` 和未受管文件不属于替换范围。已被用户修改的受管文件、文件冲突或哈希不符会阻止更新。

便携包使用 `application-files.json` 定义受管文件。Git 使用副本要求 main 干净，只快进到对应正式标签，不重置历史；私人忽略文件保留。成功后清理本次暂存和临时恢复副本；失败且需要恢复时保留本次材料。v0.5.3 旧命令行包不具备桌面更新清单，首次切换需由维护者同步完整桌面版。

## 维护与验证

完整项目回归包含桌面和更新测试。桌面测试覆盖表单、菜单、默认值、数值 0、清空、隐藏凭据、页面切换、取消边界、草稿加密保存、任务结果和当前用户命名管道；更新测试覆盖路径越界、篡改、私人数据保留、冲突、失败回滚和 Git 快进。

正式发版前更新 `config/application.json` 的版本并将 channel 设为 stable，在干净 main 上运行：

```powershell
pwsh -NoProfile -File .\scripts\New-VpsReleasePackage.ps1 -Destination '<发布输出目录>'
```

该脚本只从公开 Git 文件清单打包，保密检查后生成文件清单和校验值，再解包复验。预览包使用 `-Development`，文件名带 `ui-preview`，应用更新不会将其当成正式附件。打包不等于已经推送、发布或安装。
