收尾检查确认原 Reality 配置摘要相同、服务仍运行，原主 SSH 和救援 SSH 均可通过已信任主机身份与管理密钥认证，本轮 SS、Agent 与主控的程序、配置、服务文件及监听已移除。最后一次应用健康审计成功，后台进程安全退出，激活与前台采样均为 0。正式应用的私人归档未用于写入测试结果，恢复证据保留在独立测试目录。

真实测试发现并修正了两处追加安装缺漏：Komari 1.5.1 没有 `--version`，以成功退出且不启动服务的 `--help` 版本横幅核对；Agent 安装补齐其脚本要求的节点名称。Komari 维护与恢复使用同样的版本核对方式。真实主控安装在修正后通过，原始失败也已按组件范围恢复。

失败或取消后，任务历史及实例状态保留原中断阶段，恢复过程不覆盖原错误位置。未确认的恢复仍独立显示待恢复。

## 明确未测

- AnyTLS/ECH 的真实证书签发与联网连接：本轮没有专用测试域名及对应授权材料；已验证表单、参数边界和隔离恢复逻辑。
- 专用 Cloudflare Tunnel 的真实连接与公开域名路由：本轮没有专属测试 Token；表单及隔离安装、轮换与范围恢复回归已执行。
- 实际鼠标拖动、滚轮命中、系统文件选择器、UAC、多显示器体验：后台接口未使用电脑操控，不将逻辑或渲染测试当成物理手势验收。
- 全新重装后的整套部署、IPv6 专用 SS 第二用户、旧版数据库跨版本迁移及所有网络故障组合：本轮没有完成这些实机场景。

域名和 Token 缺失的联网项目按使用者选择标记未测，继续完成其余测试并发布。原有应用更新下载链路未作功能改动，本轮没有重复公开新版发现、下载与安装的实测全链路。

详细图像、SSH 证据、客户端结果与恢复材料保存在本地私人测试工作区；公开记录只保留测试对象与结果，不包含实际地址、端口或凭据。
