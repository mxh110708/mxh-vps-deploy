# 本轮升级验收记录

## 本地实现

- 配置工作台替代默认长向导，支持节点与连接关系局部编辑、私有加密草稿、来源刷新、独立生成和发布。
- 发布加入脱敏差异摘要、候选/来源/目标指纹、协作锁、唯一备份、阶段记录及中断恢复入口。
- 协议与 SSH 维护增加远端事务所有者及预期恢复点校验；SSH 本地阶段记录、只读新旧入口探测和恢复处理。
- 手动恢复区分范围，先准备候选、本地应用，再提交远端；中断记录可以核实或回滚。
- 修复已列明的菜单返回边界，合法数值 0 的字段支持 `/back`，敏感输入前置于事务。

## 验证结果

本轮在 Windows、PowerShell 7.6.5 下执行：

- 完整离线测试：758 项断言通过，包含 PowerShell/Bash 语法、既有计划与配置生成、DryRun 和秘密值扫描。
- 交互回归：40 项断言通过。
- 工作台回归：31 项断言通过，包括真实 Python 候选生成、加密草稿、差异摘要脱敏、发布冲突与中断恢复。该组中的客户端核心检查使用替身，不能将其单独解释为真实核心验收。
- 隔离远端事务测试：14 个用例通过，检查身份绑定、重复提交、活动锁拒绝、回滚与状态标记契约。
- 直接命令行 DryRun 走查：进入工作台后逐级返回配置设计器，退出码 0。
- Git 差异空白检查通过。

复现完整测试：

```powershell
pwsh -NoProfile -File .\tests\Run-Tests.ps1 -ProjectRoot $PWD
```

## 尚未验收的边界

- 没有连接、升级或修改任何生产 VPS。Debian 12/13 的真实服务调度、真实跨进程文件锁、SSH 断连、计时器到期和两个控制端并发，需在可恢复测试实例验证。CI 配置已加入隔离测试，但本轮没有运行远端 CI。
- 旧长向导仍是显式兼容入口，其所有历史字段没有全部迁移到新工作台的交互模型。
- 任意高级 DNS/TUN/规则的可视化编辑未加入；通过导入只读基础配置保留。导入模式的重命名与删除边界见工作台说明。
- 旧版本仍在运行的未完成事务不会被强制接管，需先用原版本/原计划结束或恢复；新版本不会覆盖其保护单元。
- 草稿使用 Windows 当前用户加密，不保证跨账号/跨设备打开；候选和旧归档沿用原有目录权限，不是自动加密文件。
- 不宣称两文件或本地/远端联合硬件级原子提交。阶段记录用于识别与恢复中断，外部修改或损坏备份会导致自动恢复停止。

代码和文档只在本地修改，未自动提交或推送 Git。
